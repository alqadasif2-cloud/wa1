# TRUST WALLET PRO 🛡️

تطبيق محفظة عملات رقمية تجريبي متكامل لنظام Android والويب، بتصميم احترافي مستوحى من Trust Wallet مع دعم كامل للغة العربية والإنجليزية، ونظام التحويل الذري، والتقييد المؤقت للأموال بعدادات تنازلية حية، والإشعارات، ولوحة تحكم المالك وسجلات التدقيق.

## 🌟 ميزات المشروع الرئيسية

1. **إدارة المحافظ والأرصدة:**
   - عرض إجمالي الرصيد التجريبي بالدولار والعملات الرقمية (USDT, BNB, ETH, BTC).
   - فصل دقيق بين **الرصيد المتاح للإرسال** و**الرصيد المقيد مؤقتاً**.
   - صنبور رصيد تجريبي (Faucet) لشحن أرصدة اختبارية بنقرة واحدة.

2. **عناوين الاستقبال الفريدة ورموز QR:**
   - عنوان استقبال فريد لكل مستخدم (`0x...`).
   - توليد ديناميكي لرمز QR مع نسخ فوري وتنبيه للمستخدم.
   - دعم شبكات BEP20 و ERC20 و TRC20 مع توضيح صريح بأن العناوين للمحاكاة الآمنة.

3. **نظام الإرسال والتقييد الزمني (Time-Locking):**
   - إمكانية تحديد مدة حظر المبلغ (5 د، 15 د، 30 د، 1 ساعة، 6 ساعات، 12 ساعة، 24 ساعة، أو مدة مخصصة).
   - عداد تنازلي حي (`00:14:32`) يتحدث بالثانية.
   - تحرير تلقائي فوري للمبلغ عند وصول المؤقت للصفر ونقله إلى الرصيد المتاح دون الحاجة لتدخل يدوي.
   - احتساب الوقت اعتماداً على توقيت النظام لمنع التلاعب بساعة الهاتف.

4. **لوحة تحكم المالك (Owner Dashboard):**

   - إدارة المستخدمين، وتعديل الأرصدة (إضافة أو خصم) مع إلزامية توثيق سبب التعديل.
   - إيقاف وتنشيط الحسابات.
   - فك التقييد المبكر بقرار إداري.
   - سجل تدقيق إداري غير قابل للتعديل (`admin_audit_logs`).

## 📱 بناء تطبيق Android بصيغة APK

المشروع مهيأ بالكامل ليتم بناؤه وتصديره بصيغة APK إما محلياً أو آلياً عبر **GitHub Actions**.

### 1. البناء التلقائي عبر GitHub Actions (الطريقة الأسهل):
1. قم بإنشاء مستودع جديد على GitHub وارفع ملفات المشروع إليه:
   ```bash
   git init
   git add .
   git commit -m "Initial TRUST WALLET PRO commit"
   git branch -M main
   git remote add origin https://github.com/<YOUR_USERNAME>/trust-wallet-pro.git
   git push -u origin main
   ```
2. توجه إلى صفحة المستودع على GitHub واضغط على تبويب **Actions**.
3. ستجد سير عمل **Android APK Build (TRUST WALLET PRO)** يعمل تلقائياً (أو يمكنك تشغيله يدوياً عبر زر **Run workflow**).
4. عند اكتمال البناء بنجاح (علامة صح خضراء):
   - افتح تفاصيل التشغيل.
   - انزل إلى قسم **Artifacts** في أسفل الصفحة.
   - اضغط على **trust-wallet-pro-debug-apk** لتنزيل ملف الـ APK وتثبيته مباشرة على هاتفك!

### 2. البناء محلياً على جهاز المطور:
- **المتطلبات:**
  - JDK 17 (Java Development Kit)
  - Android SDK (Platform 34)
- **أمر البناء:**
  ```bash
  # أنظمة Linux / macOS:
  chmod +x gradlew
  ./gradlew assembleDebug

  # أنظمة Windows:
  gradlew.bat assembleDebug
  ```
- **مسار ملف APK الناتج:**
  ```
  app/build/outputs/apk/debug/app-debug.apk
  ```
